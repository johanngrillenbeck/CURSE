# Map selected tracks MIDI input to OMNI - disable mapping

| Info and Status         |                 |
| ----------------------- | --------------- |
| Spec'd                  | ✅               |
| Implemented             | ✅               |

Disables "Map input to channel" (sets it to omnichannel / -1) on all selected tracks.
