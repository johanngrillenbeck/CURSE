# CURSE (Collection of Useful Reaper Scripts and Enhancements)

## User Documentation

For the documentation of the project and each and every script, go to the [User Documentation](https://curse.johanngrillenbeck.de) hosted online (also available in markdown format in this repo under `Docs`).

## State of the project

Some of the scripts in CURSE I use daily, some I have only made for a specific one-off usecase and did not test them any further.
Some are ... kind of abandoned.

Feel free to get inspired for your own scripts or leave me feedback about where I should maybe dive a bit deeper.

## Development Documentation

### Environment

#### reapack-index
Install ruby, cmake and pandoc. Then use `bundle install` at the repo root.

#### docs via jekyll
Install ruby. Then use `bundle install` at /Docs.
